## Implementation Instructions

1. Implement `worker.hpp` defining the `WorkerThread` class. It manages a `std::thread` executing assigned operators.
2. In the thread scheduling loop, execute all assigned operators in a round-robin loop.
3. Apply cooperative three-tier backoff policy when all operators are idle:
   - For `idle_rounds` < `SPIN_BEFORE_YIELD`, execute assembly `yield` (on AArch64) or `pause` (on x86-64).
   - For `idle_rounds` < `SPIN_BEFORE_YIELD + YIELD_BEFORE_SLEEP`, call `std::this_thread::yield()`.
   - For higher `idle_rounds`, sleep for `SLEEP_NS` nanoseconds.
4. Apply core affinity mapping using `apply_affinity` at thread startup.
5. On thread exit, ensure `shutdown()` is called on all assigned operators and clear the operators list.

## Predicted Failure Modes

- **100% CPU Burning on Empty Queues:** If the three-tier backoff yields and sleeps are missing or bypassed, idle worker threads will consume 100% of a core, degrading system performance and masking throughput metrics under real load.
- **Lost Wakeups/Operator Stalls:** If operators returned Blocked or Idle but input arrived without proper scheduler check, tasks can be stalled indefinitely.
