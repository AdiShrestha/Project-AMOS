## Implementation Instructions

1. Implement `operator.hpp` defining the `OpStatus` enum (Processed, Idle, Blocked) and the abstract `IOperator` interface. `IOperator` must define virtual methods `init()`, `tick()`, `shutdown()`, and `attach_metrics()`, and own a unique `id` and `name_` string.
2. Implement `backpressure.hpp` containing `EMAOccupancyTracker` (templated on queue type, updating an EMA metric of queue occupancy), `TokenBucketRateLimiter` (token replenishment and consumption for rate limiting), and `BackpressureSignal` struct.
3. The `BackpressureSignal` struct must contain:
   - `std::atomic<double> ema_occupancy`
   - `std::atomic<uint32_t> current_W`
   - `std::atomic<double> current_alpha`
   This struct is shared across threads, so its members must be atomic to prevent concurrency issues and ensure clean ThreadSanitizer runs.
4. Ensure all code compiles cleanly under C++17.

## Predicted Failure Modes

- **ThreadSanitizer Warning on Shared Signal:** If `BackpressureSignal` fields are not atomic, concurrent reads and writes between the window operator and the feature extraction operator will trigger ThreadSanitizer data race errors.
- **Float/Double Rounding Errors in Token Bucket Limiter:** Incorrect time elapsed calculations can cause token leakage or starvation. Ensure `std::chrono::duration<double>` is used correctly.
