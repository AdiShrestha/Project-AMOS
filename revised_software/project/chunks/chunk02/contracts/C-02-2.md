## Implementation Instructions

1. Implement `spsc_queue.hpp` as a bounded, lock-free, single-producer / single-consumer ring buffer. Use cached indices to eliminate false sharing cache invalidations. Ensure aligning atomic indexes on different cache lines using `CACHE_LINE_SIZE` alignment.
2. Implement `mpmc_queue.hpp` as a multi-producer multi-consumer queue using the Dmitry Vyukov algorithm. Ensure that the sequence numbers are properly initialized, compared, updated with correct atomic read/write memory orders (`acquire`, `release`, `relaxed`).
3. Ensure both queue implementations static-assert that the template parameter `T` is trivially copyable.
4. Ensure both queues implement `occupancy()` and `capacity()` methods.

## Predicted Failure Modes

- **Incorrect Memory Ordering in MPMC CAS:** Wrong memory order parameters on `compare_exchange_weak` or sequence store can lead to data races or memory corruption on weaker memory models (like ARM-based Macs). Ensure `std::memory_order_acquire` and `std::memory_order_release` are used precisely where documented.
- **Data Races on Index Access:** Relaxed index load/store must only be used where ordering invariants are not violated.
