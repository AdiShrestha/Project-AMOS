## Implementation Instructions

1. Transcribe and implement `config.hpp` defining cache line sizes, queue default capacities, worker backoff spins, sleep times, and metrics intervals.
2. Transcribe and implement `event.hpp` defining the core templated `Event<Payload>` struct containing monotonic nanoseconds timestamp, routing/grouping key, sequence number, and user payload. Ensure payload type constraints (trivially copyable) are commented.
3. Transcribe and implement `metrics.hpp` implementing `Counter` (cache-line aligned atomic counter with relaxed semantics), `LatencyHistogram` (fixed-width histogram for latency tracking), and `MetricsReporter` (background thread printing statistics).
4. Transcribe and implement `pinning.hpp` defining the `CoreAffinity` enum and `apply_affinity` function with platform-specific conditional branches for macOS QoS classes and Linux affinity mapping if present.
5. All code must compile cleanly under C++17 without warnings.
