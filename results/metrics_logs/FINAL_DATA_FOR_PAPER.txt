SECTION I: OPEN ISSUES REQUIRING AUTHOR JUDGMENT

  ISSUE 1 — Negative regret for static baselines:
    Static architectures (FR≈-0.016) outperform oracle (α=0.20) because
    α=0.10 (span≈19) better captures accumulated purchase intent than
    reactive α=0.20 (span≈9). Paper must explain this is a task-specific
    finding, not a measurement error. Section 7 draft paragraph written.

  ISSUE 2 — Ablation shows B-only ≈ Adaptive on regret (CI overlap):
    B-only [+0.0039, +0.0048] vs Adaptive [+0.0017, +0.0046] overlap.
    Mechanism A's marginal accuracy benefit is not statistically significant
    in MaxRate regime. The stress experiment should differentiate them on PATR.
    Paper should state this honestly: 'B is the dominant accuracy mechanism;
    A's benefit is throughput retention under load.'

  ISSUE 3 — PATR identical across non-RALF architectures in MaxRate:
    All show PATR=0.128. This is the burst event fraction in the dataset.
    Wall-clock PATR should differentiate architectures in the STRESS experiment.
    Paste stress experiment PATR values here when available.

  ISSUE 4 — ULB high WOR (~922 dir_changes/min):
    Controller oscillates heavily on single-key ULB. This is a legitimate
    finding about the mechanism's operating envelope. Paper should include
    a Discussion paragraph on single-key limitations.

  ISSUE 5 — oracle_auroc=0.6557 is below the 0.70 threshold:
    Regret numbers are still valid — they show relative differences between
    architectures on a common baseline. Include the oracle AUROC prominently
    in Section 5 so readers can calibrate the absolute magnitudes.
