# Release scope and limits

`READY_FOR_HUMAN_SUBMISSION_REVIEW` means the frozen evidence is internally admissible and the required adversarial review is recorded. It is not “publication ready,” a guarantee of scientific truth, external validity, causal identification, novelty, or journal acceptance.

The gate cannot determine whether an agent lied while producing a correctly hashed file, whether a dataset represents its target population, whether a scientific operator is mathematically appropriate for a domain, whether an OOD shift is deployment-realistic, or whether an energy sensor was calibrated. Those decisions are assigned to the Architect review and must be supported by specific evidence or disclosed as limitations. The certificate prints these non-automated limits so a clean exit cannot be quoted as a stronger claim.
