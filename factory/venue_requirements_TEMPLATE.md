# Venue requirements template

Record the exact venue/version/date and primary URL. Copy reporting, data/code/protocol, statistical, compute, supplementary, preregistration, and disclosure requirements into `project/methodology.md`. For each requirement give a manuscript location, artifact path, hash, and status. “The venue requires rigor” is not evidence.

### Evidence sufficiency

State the sample-size, class-balance, convergence, and imbalance handling evidence supporting each comparative claim. Domain-specific deviations from the Factory defaults require a cited methodological rationale.
