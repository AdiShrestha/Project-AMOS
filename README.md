# BPFeat — Backpressure-Driven Elastic Feature Windows for Real-Time ML Pipelines

**Project 3 in a three-project IEEE-conference research arc**

> *"Backpressure drives two actuators simultaneously: how often a per-key feature snapshot is republished to a downstream model (discrete, AIMD-controlled window size W), and how reactive that feature's EMA is to recent events (continuous, slew-rate-bounded IIR pole α). We validate both inside a real, multi-threaded, lock-free C++17 stream runtime against three baselines and evaluate via downstream model regret — not a proxy metric."*

## Building

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
```

### Requirements
- CMake ≥ 3.16
- C++17-capable compiler (GCC ≥ 9, Clang ≥ 10, MSVC 2019+)
- pthreads (auto-detected)
- **No external C++ dependencies** — pure STL + pthreads

```bash

cd build && cmake .. && make -j$(nproc)

./feature_flow_harness --synthetic --seeds 5 --out-dir results/raw/

## Data Setup (Required for Real Experiments)

### Taobao UserBehavior (Primary)
1. Register at [Alibaba Tianchi](https://tianchi.aliyun.com/dataset/649) (free account required)
2. Download `UserBehavior.csv` → `data/raw/UserBehavior.csv`
3. ```bash
   python preprocessing/preprocess_taobao.py \
       --raw data/raw/UserBehavior.csv \
       --out data/replay/replay_taobao_10k.csv \
       --n-users 10000
   ```

### ULB Credit Card Fraud (Secondary)
1. Download from [Kaggle](https://www.kaggle.com/mlg-ulb/creditcardfraud) → `data/raw/creditcard.csv`
2. ```bash
   python preprocessing/preprocess_ulb.py \
       --raw data/raw/creditcard.csv \
       --out data/replay/replay_ulb.csv
   ```

### Train the Oracle Classifier
```bash
python preprocessing/train_classifier.py \
    --replay data/replay/replay_taobao_10k.csv \
    --out models/classifier_weights.txt
```

## Running All Architectures

```bash
# Four architectures, single run
for arch in fixed drift throttle adaptive; do
    ./build/feature_flow_main \
        --arch $arch \
        --replay data/replay/replay_taobao_10k.csv \
        --model models/classifier_weights.txt \
        --out results/raw/results_${arch}_seed0.csv
done
```

## Research Questions

| RQ | Question | Addressed by |
|---|---|---|
| RQ1 | Can one `EMAOccupancyTracker` drive both a discrete (W) and continuous (α) actuator simultaneously? | Experiment 1 |
| RQ2 | Do the two control laws produce empirically consistent effective-memory trajectories? | Experiment 6 |
| RQ3 | Does BPFeat achieve a more favorable PATR-vs-regret Pareto frontier than all three baselines? | Experiments 2–3 |
| RQ4 | Does the mechanism generalize to ULB's structurally different workload? | Experiment 5 |
